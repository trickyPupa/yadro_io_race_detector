Автор: Лабор Тимофей Владимирович

## Задание

Цель задания — разработать простое I2C-устройство для QEMU, продемонстрировать навыки работы с низкоуровневым кодом, эмуляцией железа и интеграцией между гостевой системой и хостом через QMP.

Полный текст задания: [test_task.md](test_task.md).

## Выполнение 

Используемая версия ядра Linux - 6.6.123.2 (6.6.123.2-microsoft-standard-WSL2+)

Исходный код представлен в файле [dm-race-detector.c](dm-race-detector.c).

Сборка:
```sh
make
```

Запуск небольшого теста:
```sh
chmod +x test.sh
./test.sh
```

Предупреждения будут выведены в консоль.


Очистка:
```sh
make clean
```
